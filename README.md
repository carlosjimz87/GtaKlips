# GtaKlips

Web en español para descubrir una selección diaria de clips de GTA VI, con candidatos de Twitch y captación orgánica desde X.

[Plan de producto y MVP](plan-gtaklips.md)

## Estado

Planificación inicial. El MVP contempla una selección manual de clips, ediciones por fecha y un borrador de publicación para X. La importación automática y las métricas se incorporarán en etapas posteriores.
